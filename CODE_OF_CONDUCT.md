# Code of Conduct

## Our commitment

OdinCore is intended to be a welcoming open-source project for the .NET community. Contributors, users, and maintainers should be able to participate without harassment or hostility.

## Expected behavior

Please:

- be respectful and constructive
- discuss technical ideas rather than attacking people
- assume good intent while asking for clarification when needed
- give actionable feedback
- welcome contributors with different experience levels and backgrounds
- keep issue and pull-request discussions relevant to the project

## Unacceptable behavior

Harassment, insults, threats, discrimination, deliberate disruption, doxxing, or other abusive behavior is not acceptable in project spaces.

## Enforcement

Project maintainers may edit, hide, or remove comments, issues, pull requests, or other contributions that violate these expectations. Repeated or serious violations may result in temporary or permanent restrictions from project spaces.

## Scope

This code of conduct applies to the OdinCore repository and other official project spaces.
